[2026-04-10] v0.6.0: Web visualization SHIPPED — live at https://chenzhan4321.github.io/diatessaron-synopsis/. Brill-style scholarly web app with five views (Home, Parallel, Diatessaron Explorer, Gospel Refs, About). Diatessaron Explorer features a seven-language parallel table (Greek SBLGNT / Peshitta / Old Syriac Curetonian / Old Syriac Sinaiticus / Arabic Ciasca / Hogg English / KJV English) with column visibility toggles. Each row = one Hogg sub-verse, with Arabic extracted by verse marker (١)(٢) and Greek/Peshitta/Syriac/KJV looked up via Hogg's marginal gospel references. Arabic segmented into 44/55 sections via LIS-based marker detection. Vanilla HTML + Alpine.js + hash routing, no build step. Playwright-verified. KJV added as reference English (translated from Greek) alongside Hogg (translated from Arabic) so users can see the translational distance.
